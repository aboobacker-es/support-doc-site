Workday integrates with HackerRank for Tests to facilitate an easy and seamless Test experience. As part of the workflow, the recruiters can trigger test invites to candidates directly from the **Workday Recruiting**  portal. Candidates receive the HackerRank Test invites and take up the challenges. Once done, their score and performance data are automatically available in Workday for further evaluation.

Please refer to the following articles to set up various features of the Workday - HackerRank integration: 

  * [📄 Workday - HackerRank Tests Configuration Guide](</articles/1782819445>)

  * [📄 Workday - HackerRank Tests User Guide](</articles/1999755553>)

  * [📄 Workday - HackerRank Interviews Configuration Guide](</articles/4722432610>)
